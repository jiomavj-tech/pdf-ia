Falta ligar o Firebase. O aplicativo está pronto, mas ainda não sabe com qual banco falar.
  1. Em console.firebase.google.com, crie o projeto giba-chopeiras.
  2. Authentication → Sign-in method → Google: ativar.
  3. Firestore Database → Criar banco: modo produção, região southamerica-east1.
  4. Configurações do projeto → Seus apps → Web: registre um app e copie o bloco firebaseConfig.
  5. Cole esse bloco em index.html, na constante CFG, e publique as regras com firebase deploy --only firestore.
  6. Em Authentication → Settings → Domínios autorizados, acrescente o domínio onde a página está publicada.
